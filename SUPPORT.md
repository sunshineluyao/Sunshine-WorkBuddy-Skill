# Support / 支持

[English](#english) · [简体中文](#简体中文)

## English

For usage questions, release feedback, or verified contact options:

- Visit the [author's GitHub profile](https://github.com/sunshineluyao) and use a contact channel the author has chosen to publish there.
- After the SkillHub listing is live, use its detail-page feedback channel for marketplace-specific issues.

This repository is currently private, so GitHub Issues are not a public support route. Do not post credentials, identity documents, private ledgers, confidential client data, or exploit details in a public channel.

For a security concern, first send a minimal description through a verified private channel listed on the author's GitHub profile. Include the affected version and safe reproduction steps, but no real secrets or personal data. The maintainer will coordinate a safer channel if more detail is required.

The project offers general career and business experiment design. Legal, tax, immigration, medical, and investment questions require an appropriately qualified local professional.

## 简体中文

如需使用帮助、版本反馈或查找经作者确认的联系方式：

- 访问[作者 GitHub 主页](https://github.com/sunshineluyao)，使用作者主动公开的联系渠道；

如发现安全问题，请先通过作者 GitHub 主页列出的可信私密渠道发送最少必要说明，包括受影响版本和安全的复现步骤，但不要附带真实密钥或个人数据。若需要更多细节，维护者会协调更安全的沟通方式。

本项目只提供一般性的职业与商业实验设计。法律、税务、移民、医疗和投资问题应咨询当地具备相应资质的专业人士。
