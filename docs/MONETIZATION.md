# SkillPay 商业化路线

## 最小可行产品

正式产品名使用“跨界数字游民财富导航”；“成为交叉赛道的数字游民首富”只作为传播口号，并明确不承诺收入。

| 层级 | 用户结果 | 建议载体 | 初始价格假设 |
|---|---|---|---:|
| 免费快速画像 | 一句话定位、三个机会、一个48小时动作 | 当前开源 Skill | ¥0 |
| 付费深度路线 | 透明评分、机会比较、12周里程碑、证据资产和风险核验 | Pay Skill 后端服务 | 首轮测试 ¥6.9 与 ¥12.9 / 次 |
| 付费季度复盘 | 用新证据更新决策，给继续/调整/停止判断 | Pay Skill 后端服务 | 首轮测试 ¥3.9 与 ¥6.9 / 次 |
| 机构工作坊 | 团队能力地图与跨界项目组合 | 人工审核的机构服务 | 先访谈后报价 |

价格是待验证假设，不是收益承诺。每个价格至少观察30次有效到达或10次真实购买，再调整；同时记录退款、完成率和用户是否真的执行第一步。

## 为什么先免费后按次

免费层证明技能理解用户并形成分发；付费层出售更深的个性化计算、持续更新与可审计报告。SkillPay 当前支持对话内按次支付，个人与企业均可接入，商家自主定价，平台页面写明暂不收技术服务费；支付渠道自身规则仍适用。

## 付费壁垒

不要把收费仅建立在更长的提示词上。付费版应逐步增加：

1. 经同意积累的匿名结果基准与阶段转移数据；
2. 可更新的国家、平台、项目与买方证据库；
3. 用户历史版本、实验结果和决策差异；
4. 可回查来源、专业复核入口与机构模板。

需要保护的付费逻辑留在后端；公开仓库只保留本地可用的核心方法、透明评分与安全边界。

## 关键指标

- 激活：首次会话是否生成可理解的一句话定位；
- 证据：48小时动作的完成率；
- 价值：用户是否因报告改变、确认或停止一个真实选择；
- 付费：快速画像到深度路线的转化率；
- 留存：30天内是否带新证据回来复盘；
- 信任：引用可回查率、待核验标注率、退款与投诉率。

## 上线顺序

1. 发布当前免费 Skill，收集15–20次访谈和至少30份结构化反馈；
2. 手工交付10份深度路线，识别真正重复的计算与模板；
3. 再将重复部分封装为后端 Pay Skill，避免过早开发；
4. 以一个窄人群首发，例如“研究 / 教育 / AI产品的跨界知识工作者”；
5. 有案例后再扩展到独立顾问、创作者与一人公司。
