# WorkBuddy 用户需求与竞争扫描

快照日期：2026-09-13。目标是判断 WorkBuddy 用户会安装什么技能，并验证“跨界数字游民财富导航”是否存在可收费的市场空白。

## 方法与限制

本轮使用三类公开信号：WorkBuddy 官方功能与实践案例、SkillHub 下载量排序及关键词结果、公开报道中的用户任务与失败点。下载量是累计需求代理，不等于独立活跃用户、付费人数或收入；关键词数量会受检索召回影响。本轮不是代表性抽样调查，因此同时提供可继续收集一手反馈的问卷。

## 用户会用怎样的技能

截至快照日，SkillHub 页面显示约15万项技能。下载量靠前的公开条目显示五类强需求：

| 需求簇 | 公开信号 | 用户真正购买的结果 |
|---|---|---|
| Agent与开发工具 | self-improving agent 119.1万、Find Skills 95.1万、编程专家 83.6万、Agent Browser 78.3万 | 少配置、少返工、任务能跑完 |
| 办公与知识工作 | 腾讯文档 94.4万、Summarize 61.0万、搜索引擎 46.6万、ima 32.8万 | 文件和知识能直接形成交付物 |
| 数据与视觉交付 | smart-charts 33.2万、架构图一键生成 21.2万 | 从原始材料到可展示成果 |
| 信任与专业判断 | Skill Vetter 30.9万、法律专业技能约30.8万、防骗约30.0万 | 来源可核验、风险可解释 |
| 内容与个人影响力 | 多模态创作约28.1万、Humanizer约26.9万、中文去AI味约22.1万 | 可发布、像真人、能触达受众 |

WorkBuddy 官方实践案例也集中在文件处理、文档生成、数据可视化、自媒体、资讯简报、会议和零代码应用。公开用户反馈反复出现长任务中断、上下文丢失、文件管理混乱、跨端同步和积分成本问题。因此，高价值技能应缩短链路、保存中间决策、明确证据状态并交付可复用文件。

## 目标交叉位

| 关键词 | 结果规模或代表信号 | 竞争判断 |
|---|---|---|
| 职业规划 | 约296项；相关头部约3,900–5,300下载 | 供给多，但多为测评与岗位建议 |
| 领导力 | 约193项；多为产品、管理或单一岗位 | 缺少全球、跨界、可验证项目路线 |
| 副业 | 约242项；一人公司约1.1万下载 | 有付费意愿线索，但泛运营同质化明显 |
| 数字游民 | 精确搜索仅13项；通用技能约743下载 | 主要是城市、签证、旅居和远程岗位目录 |
| 全球领导力 | 精确搜索仅3项 | 没有面向个人的综合导航技能 |

市场空白不是“再做一个城市攻略”，而是帮助高技能知识工作者回答：我的哪组跨界能力可被全球买方验证？怎样在不孤注一掷的情况下建立可携带收入、影响力和选择权？

## 优先用户画像

1. **跨界知识工作者（首发）**：研究、教育、咨询、产品、数据或内容领域已有成果，想从单一机构收入转向全球组合；付费动机是减少错误转型和明确首个实验。
2. **独立专业人士与一人公司**：已有服务但定位、产品化和分发不稳；付费动机是把小时劳动转为复利资产。
3. **高潜学生与早期职场人**：愿意建立全球作品集但支付能力较弱；适合作为免费增长层和高校合作层。

## 15分钟一手访谈

先访谈15–20名用户；不询问精确收入、证件或雇主机密。

1. 过去30天你最希望 WorkBuddy 替你完成的三项工作是什么？
2. 哪一次任务看似完成但你最终不敢使用？为什么？
3. 你目前最依赖的三个技能是什么？它们替你节省了什么？
4. 你是否想建立不依赖单一雇主、客户、平台或地点的职业组合？
5. 你更需要地点选择、远程岗位、跨界定位、客户验证、作品集还是收入组合？只能选两项。
6. 如果一个技能能交付“一句话定位 + 三条机会 + 90天验证计划”，你会在什么情境下立即使用？
7. 你会相信哪些证据：公开案例、方法透明、引用来源、专业身份、朋友推荐或试用结果？
8. 对一次深度个性化报告，你更能接受：免费、¥1–5、¥6–15、¥16–49、¥50以上，还是只愿为真人复核付费？
9. 哪类数据你绝不会交给技能？
10. 90天后，什么可观察变化会让你认为它值得续用？

仓库的 GitHub Issue Form 已将这些问题压缩为可公开收集的匿名需求表。先看选择与行为，再问“喜不喜欢”；先验证付费结果，再开发复杂功能。
