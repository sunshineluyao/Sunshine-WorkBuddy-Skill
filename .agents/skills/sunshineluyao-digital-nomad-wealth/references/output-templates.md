# Output Templates / 输出模板

Render labels and prose in the user’s language. For a bilingual request, produce the complete Chinese version first and the matched English version second; keep numbers, evidence states, and citations aligned.

默认使用用户语言。当用户要求中英双语时，先给完整中文版，再给对应英文版；两版的数字、证据状态和引用必须一致。

## Quick profile / 快速画像

### One-sentence positioning / 一句话定位

`I help [specific buyer] solve [costly problem] by combining [defensible intersection], demonstrated by [verifiable result].`

`我帮助[细分买方]用[有壁垒的跨界组合]解决[高成本问题]，并以[可验证结果]证明价值。`

### Research snapshot / 研究快照

State the exact as-of date, geography, verified signals with nearby sources, conflicts, inference, and the highest-value unknown. Omit this section when no current claim affects the decision.

写明准确的截至日期、地区、带就近引用的已核验信号、冲突、推断和价值最高的未知项。如果没有会影响决策的时效性事实，可省略。

## 90-day lighthouse experiment / 90天灯塔实验

### Days 1–30 · Problem evidence / 第1–30天 · 问题证据

- One buyer hypothesis / 一个买方假设;
- 5–10 consent-respecting interviews or direct observations / 5–10次合规访谈或直接观察;
- One demonstrable minimum sample / 一个可展示的最小样品;
- Continue / adjust / stop threshold / 继续、调整、停止阈值.

### Days 31–60 · Delivery evidence / 第31–60天 · 交付证据

- 1–3 small real deliveries / 1–3个小规模真实交付;
- Before/after difference, delivery time, and objections / 前后差异、时间成本与异议;
- Convert repeated work into a template or process / 把重复劳动整理成模板或流程;
- Continue / adjust / stop threshold / 继续、调整、停止阈值.

### Days 61–90 · Compounding evidence / 第61–90天 · 复利证据

- One public or privately shareable case / 一个可公开或定向展示的案例;
- One repeatable reach channel / 一个重复触达渠道;
- One fallback that reduces location, client, or platform concentration / 一个降低地点、客户或平台集中度的备选;
- Scale, revise, or exit decision / 下一季度扩大、调整或退出决策.

保留失败和冲突证据。若用户未授权持久化，只返回事件 JSON，不写入文件。

## Full roadmap / 完整路线图

After the quick profile, add an evidence ledger, stakeholder map, opportunity comparison, 12-week milestones, budget and time caps, professional-verification checklist, contingency, and learning-review cadence. Use only when a formal deliverable is requested and evidence is sufficient.

在快速画像之后追加：证据账本、利益相关者地图、机会比较、12周里程碑、预算与时间上限、专业核验清单、失败预案和学习复盘节奏。只有用户需要正式交付物且证据充分时使用。
