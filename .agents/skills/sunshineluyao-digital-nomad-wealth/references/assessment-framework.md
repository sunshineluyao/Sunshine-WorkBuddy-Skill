# Compound-Advantage Assessment / 跨界复利优势评估

Score only when the user has enough evidence to support a judgment. Each axis uses 0–5. Give a range or “unresolved / 待验证” when evidence is weak. Scores compare paths and reveal bottlenecks; they do not predict income.

只有用户信息足以支持判断时才评分。每项使用0–5分；证据不足时给区间或标记“待验证”。分数用于比较路径和发现瓶颈，不预测收入。

## Seven capabilities / 七项能力

| Axis / 维度 | Weight / 权重 | 0 anchor / 0分 | 3 anchor / 3分 | 5 anchor / 5分 |
|---|---:|---|---|---|
| Expertise evidence / 专业证据 | 20% | Interest only / 只有兴趣 | Inspectable work or result / 有可查看作品或结果 | Repeated outcomes, recognition, transferable method / 持续成果、第三方认可、可迁移方法 |
| Portable delivery / 远程可交付性 | 15% | Fixed-site only / 必须现场 | Partly remote / 部分可远程 | End-to-end remote, standardized, cross-time-zone / 端到端远程、标准化、跨时区 |
| Global demand / 全球需求 | 15% | Buyer and pain unknown / 买方痛点不明 | Specific buyer, demand unproven / 买方明确、需求待证 | Multiple regions repeatedly pay for measurable value / 多地区持续付费 |
| Cross-domain scarcity / 跨界稀缺性 | 15% | Domains merely listed / 领域并列 | Domains complement one buyer problem / 围绕同一问题互补 | Hard-to-copy combination materially improves outcomes / 难复制且显著改善结果 |
| Distribution and network / 分发与网络 | 10% | No reach path / 无触达路径 | Small audience or partners / 有小规模受众或伙伴 | Repeatable acquisition, referral, or institutional network / 可重复获客、转介绍或机构网络 |
| Revenue durability / 收入耐久性 | 15% | One-off, one client, hourly / 单次单客户按小时 | Repeat purchase or partial productization / 有复购或部分产品化 | Multiple buyers and layers, falling marginal delivery cost / 多买方多层收入、边际成本下降 |
| Location resilience / 地点韧性 | 10% | Depends on one place or platform / 依赖单一地点或平台 | Can switch among a few locations / 可在少数地点切换 | Redundancy across place, currency, platform, and time zone / 地点、货币、平台、时区有冗余 |

## Risk deductions / 风险扣分

Use 0–5 again; 0 is very low risk and 5 is very high risk.

仍用0–5评估；0表示风险很低，5表示风险很高。

| Risk / 风险 | Maximum deduction / 最大扣分 | Check / 检查重点 |
|---|---:|---|
| Compliance and data / 合规与数据 | 8 | Visa, tax, license, privacy, IP, employment limits / 签证、税务、许可、隐私、知识产权、雇佣限制 |
| Income concentration / 收入集中 | 7 | Dependence on one client, employer, platform, country, or payment rail / 单客户、雇主、平台、国家或支付渠道依赖 |
| Capacity and burnout / 容量与倦怠 | 5 | Time, health, care, time zones, unsustainable delivery / 时间、健康、照护、跨时区、不可持续交付 |

Formula / 计算式：

`Total / 总分 = seven-axis weighted base / 七项加权基础分 − risk deductions / 风险扣分`

| Score / 分数 | Stage / 阶段 | Meaning / 含义 |
|---:|---|---|
| 0–39 | Foundation / 打底 | Add one critical proof or portable capability / 补一个关键证据或可交付能力 |
| 40–59 | Validate / 验证 | Test the buyer and problem with a small sample / 小样本确认买方与问题 |
| 60–74 | Prove / 证明 | Build repeatable cases and clear positioning / 形成重复案例与明确定位 |
| 75–89 | Scale / 扩张 | Productize, distribute, and reduce concentration / 产品化、分发、降低集中风险 |
| 90–100 | Compound / 复利 | Maintain moat, options, and resilience / 维护壁垒、选择权与长期韧性 |

## Opportunity comparison / 机会比较

For a concrete opportunity, prioritize five questions: Is the buyer pain urgent? Can the user reach a real buyer within 48 hours? Can the path produce evidence within 30 days? Is failure reversible? Does it create a long-term asset? When options are close, choose the one that produces honest feedback sooner.

比较具体机会时，优先判断：买方痛点是否紧迫、48小时内能否接触真实对象、30天内能否产生证据、失败是否可逆、是否增强长期资产。若分数接近，选择更快产生真实反馈的方案。
