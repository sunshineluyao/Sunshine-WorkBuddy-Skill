# Changelog / 版本记录

All notable changes are recorded here. Dates use YYYY-MM-DD.

所有重要变更均记录于此，日期格式为 YYYY-MM-DD。

## 1.1.0 — 2026-09-13

### English

- Added matched English and Simplified Chinese user journeys.
- Added current-information research rules, bilingual query expansion, source grading, conflict handling, and competitor comparison.
- Added a consent-based, append-only learning ledger and explicit explanation that it is not model training or hidden memory.
- Added a deterministic seven-axis scorer, test suite, GitHub-safe badges, user-experience diagram, and software architecture diagram.
- Added marketplace icons, privacy and support notices, paste-ready SkillHub listing copy, and eight acceptance cases.
- Changed the pre-release SkillHub slug to the more collision-resistant `sunshineluyao-digital-nomad-wealth`.
- Consolidated publishing onto one `main` branch and moved the canonical package to `.agents/skills/sunshineluyao-digital-nomad-wealth` for GitHub discovery.

### 简体中文

- 增加完整对齐的中英文用户旅程；
- 增加时效信息检索、双语扩展查询、来源分级、冲突处理和竞品比较规则；
- 增加经用户授权、只追加的学习账本，并明确它不是模型训练或隐藏记忆；
- 增加可复现的七维评分器、测试套件、GitHub 安全徽章、用户体验图和软件架构图；
- 增加商城图标、隐私与支持说明、可粘贴 SkillHub 文案及八个验收场景；
- 在首次上架前将 SkillHub slug 改为更不易冲突的 `sunshineluyao-digital-nomad-wealth`。
- 将发布流程收敛到唯一 `main` 分支，并把规范包迁移到 `.agents/skills/sunshineluyao-digital-nomad-wealth` 以支持 GitHub 自动发现。
